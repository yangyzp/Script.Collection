1.一键安装fake204（go）

> ◉如果clash测试访问 https://www.gstatic.com/generate_204  和 https://cp.cloudflare.com/generate_204  就显示真实延迟
>
> ◉如果clash测试访问 http://www.gstatic.com/generate_204 和 http://cp.cloudflare.com/generate_204  就命中本地 `204` ，少了落地机到`gstatic`这一段的延迟

```
if ! command -v curl &> /dev/null; then apt update && apt install curl -y; fi; rm -f install_fake204.sh; curl -L -o ./install_fake204.sh "https://raw.githubusercontent.com/yangyzp/Script.Collection/master/fake204/install_fake204.sh"; chmod +x ./install_fake204.sh && ./install_fake204.sh
```



2. soga启动参数加上 

    ` --add-host=www.gstatic.com:127.0.0.1 --add-host=cp.cloudflare.com:127.0.0.1 `

```
docker run -e node_id=4 --name=mongo1 --restart=always -d --network host --add-host=www.gstatic.com:127.0.0.1 --add-host=cp.cloudflare.com:127.0.0.1 -e type=sspanel-uim -e server_type=ssr -e api=webapi -e webapi_url=https://webapi.subscribenow.in/ -e webapi_key=uinio_mu_key -e ssr_cid_limit=true -e proxy_protocol=true -e submit_interval=120 -e random_interval_range=10 -e submit_traffic_min_traffic=250 -e submit_alive_ip_min_traffic=250 -e dns_strategy=ipv4_only -e user_tcp_limit=250 --log-opt max-size=50m --log-opt max-file=3 kenzsoft/mongov2
```

3.节点配置文件里加入

```
url: http://www.gstatic.com/generate_204
```

或者

```
url: http://www.gstatic.com/generate_204
```

journalctl -u fake204 -f
